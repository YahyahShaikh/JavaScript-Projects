# 🧠 JavaScript & jQuery Mini Projects

A collection of simple yet functional projects built using **JavaScript** and **jQuery** to strengthen core web development skills.

---

## 🚀 JavaScript Projects

### 🧮 Calculator
Developed a functional calculator using JavaScript for performing basic arithmetic operations like addition, subtraction, multiplication, and division.

### ⏰ Digital Clock
Created a real-time digital clock that dynamically displays hours, minutes, and seconds, updating every second.

### 💬 Quote Generator
Built a quote generator that fetches and displays motivational quotes on each button click, enhancing user engagement.

---

## ⚡ jQuery Projects

### 🎯 Guess the Number Game
An interactive number guessing game built with jQuery. It includes input validation and real-time feedback for a fun user experience.

### 🔢 OTP Generator
Developed a random 6-digit OTP generator using jQuery that displays a new OTP on every button click.

---

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **jQuery**

---

## 💡 How to Run
1. Clone or download this repository.  
2. Open any project folder.  
3. Launch the `index.html` file in your browser.
